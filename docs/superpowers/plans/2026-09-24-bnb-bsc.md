# Stax on BSC — Implementation Plan (BNB Hack: Tokenized Stocks Edition)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add BSC mainnet as a third Stax chain, trading bStock and Ondo tokenized stocks through the Binance Web3 API, with Vera, baskets and Autopilot working there, plus a market-hours and price-gap layer.

**Architecture:** BSC is one more `StaxChain` in `web/src/lib/chains/`, so every chain-aware path picks it up. A typed, server-only Binance Web3 client in `web/src/lib/server/binance/` is the only thing that talks to Binance. Buys run as direct ERC-4337 smart-account swaps using Binance's unsigned router calldata. The `StaxExecutor` path is built behind `contracts.deployed` and switched on after the human deploys (ADR-0005). The RWA Data API's on-chain price, reference price and market status feed a catalog that Vera, the Market screen and the buy flow all read.

**Tech Stack:** Next.js 16, TypeScript, viem 2.52, permissionless (ERC-4337 v0.7, Pimlico), Privy, Drizzle + Neon Postgres, Upstash Redis, Vitest, Hardhat.

**Spec:** `docs/BINANCE-WEB3.md` (the exact API contract, proven with live calls) · `PRODUCT.md` · `docs/DECISIONS.md` ADR-0004 to ADR-0010 · `docs/MULTICHAIN.md`. Read `docs/BINANCE-WEB3.md` before any task that calls Binance.

## Global Constraints

- BSC mainnet only, chain id `56`. Spot only. No testnet paths in product code.
- BSC cash is USDT `0x55d398326f99059fF775485246999027B3197955`, **18 decimals**, exposed as `chain.usdc` with `symbol: "USDT"`.
- Binance aggregator router, which is also the approval spender: `0xB44446b0c8E56988c34f7Ff73Ae904982b5FdDA5`.
- Minimum **$6 per leg** (`BSC_MIN_LEG_USD = 6`). Binance rejects quotes of $5 or less with `40375`.
- Platforms: `bstock` and `ondo` only. xStocks is not in the Binance API; never add it.
- No Stax fee on BSC: never send `feePercent`, `feeSource` or `*ReferrerWalletAddress` (ADR-0007).
- `WEB3_API_KEY` and `WEB3_SECRET_KEY` are server-only. Never `NEXT_PUBLIC_`, never logged, never in fixtures, never returned in an API response.
- Binance budget: `X-OC-RateLimit-Limit: 5` per window. Serialise calls; cache every read.
- The only DB migration in this effort is `web/drizzle/0010_*.sql` (Task 3). No other task generates a migration.
- Tests never sign, broadcast, swap or move funds. Binance `simulate` is allowed; `broadcast` is not.
- UI copy on BSC reads `chain.usdc.symbol`. Never hardcode "USDC" in a path BSC can reach.
- Gifts stay Base-only. No Agent Studio, no Agentic Wallet (ADR-0010).
- Verify command: `cd web && npm run verify` (tsc + eslint + vitest). Must pass before every commit.
- Commits end with the two attribution lines from the session instructions.
- Every friction with the Binance API hit during a task (a confusing doc page, an error that made no sense, a missing field, surprising latency) is appended to `F:/Tools/stax v1/stax/tasks/bnb-dx-log.md` in that file's format: UTC time from `date -u`, exact URL or endpoint, the error quoted verbatim, impact. Facts only; never write the report itself, which the human must write (the organisers reject AI-written reports).

## Review Focus

1. **The market is closed.** Submissions lock on a Sunday. A buy on a non-buyable token must show "Market closed · opens <local time>" and never send a quote. Pinned by tests in Tasks 9, 11 and 12.
2. **18-decimal cash.** A $10 buy on BSC must be `10n * 10n ** 18n` raw units, not `10_000_000n`. Anything else is a 10^12× error. Pinned in Tasks 2 and 5.
3. **Legs under $6.** "$20 across 5 stocks" must fail at planning with a message naming the $6 minimum, not at execution. Pinned in Task 12.
4. **Rate limit mid-basket.** A `429`/`418` on leg 3 of 4 must back off and retry. A basket must never half-execute silently. Pinned in Tasks 6 and 8.
5. **An RFQ route or an unexpected router.** It must be rejected before any call is returned for signing, because a contract cannot sign RFQ and an unknown router is an attack surface. Pinned in Task 8.

// same line is a 10^12x error. These helpers are the only sanctioned conversion.
import { describe, expect, it } from "vitest";
import { rawToUsd, usdToRaw } from "./units";

const six = { usdc: { address: "0x1" as const, symbol: "USDC" as const, decimals: 6 } };
const eighteen = { usdc: { address: "0x2" as const, symbol: "USDT" as const, decimals: 18 } };

describe("usdToRaw", () => {
  it("converts at 6 decimals", () => {
    expect(usdToRaw(six, 10)).toBe(BigInt(10_000_000));
    expect(usdToRaw(six, 0.01)).toBe(BigInt(10_000));
  });

  it("converts at 18 decimals without floating-point drift", () => {
    expect(usdToRaw(eighteen, 10)).toBe(BigInt(10) * BigInt(10) ** BigInt(18));
    expect(usdToRaw(eighteen, 6.5)).toBe(BigInt(65) * BigInt(10) ** BigInt(17));
    expect(usdToRaw(eighteen, 0.1)).toBe(BigInt(10) ** BigInt(17));

    expect(usdToRaw(eighteen, 1.2345678)).toBe(BigInt(1_234_568) * BigInt(10) ** BigInt(12));

    expect(() => usdToRaw(six, -1)).toThrow();
    expect(() => usdToRaw(six, Number.NaN)).toThrow();
    expect(() => usdToRaw(six, Number.POSITIVE_INFINITY)).toThrow();
  });
});

describe("rawToUsd", () => {
  it("reads back what usdToRaw wrote, at both precisions", () => {
    expect(rawToUsd(six, usdToRaw(six, 42.5))).toBe(42.5);
    expect(rawToUsd(eighteen, usdToRaw(eighteen, 42.5))).toBe(42.5);

```ts
// Dollars <-> raw cash units for any chain. Cash is 6-decimal USDC on Base and Mantle and
// 18-decimal USDT on BSC, so a hardcoded "* 1_000_000" is a 10^12x bug on BSC. Every
// conversion goes through here: exact to the micro-dollar, and never a float times 1e18.
import type { StaxChain } from "./chains";

type Cash = Pick<StaxChain, "usdc">;

export function usdToRaw(chain: Cash, usd: number): bigint {
  if (!Number.isFinite(usd) || usd < 0) throw new Error(`usdToRaw: invalid amount ${usd}`);
  const micros = BigInt(Math.round(usd * 1e6));
  const d = chain.usdc.decimals;
  return d >= 6 ? micros * BigInt(10) ** BigInt(d - 6) : micros / BigInt(10) ** BigInt(6 - d);
}

/** For display only: loses precision above 2^53 raw units, which is fine for a label. */
export function rawToUsd(chain: Cash, raw: bigint): number {
  return Number(raw) / 10 ** chain.usdc.decimals;
}
```

// token's on-chain price next to the underlying share's reference price, plus whether the
// issuer will trade it right now. Everything that shows or buys a BSC stock reads these.
import type { RwaPlatform } from "./chains";

export type MarketState = "open" | "premarket" | "postmarket" | "overnight" | "closed" | "paused" | "unsupported";

/** Binance rejects quotes of $5 or less (40375), and the floor is exclusive, so a leg needs $6. */
export const BSC_MIN_LEG_USD = 6;

export interface VenueView {
  platform: RwaPlatform;
  symbol: string;
  address: `0x${string}`;
  tokenPrice: number;
  referencePrice: number;
  /** Token premium over the reference, in percent; null when there is no usable reference. */
  gapPct: number | null;
  state: MarketState;
  buyable: boolean;
  nextOpenMs: number | null;
  updatedAt: number;
}

export interface RwaTickerView {
  ticker: string;
  name: string;
  type: "stock" | "etf" | "other";
  venues: VenueView[];
  /** The venue a buy should use right now: buyable, then the smallest gap. Null when none is. */
  bestVenue: RwaPlatform | null;
}

/** An issuer trades a token only when it is open AND its reason code says TRADING. */
export function isBuyable(s: { openState: boolean; reasonCode: string }): boolean {
  return s.openState && s.reasonCode === "TRADING";
}

export function gapPct(tokenPrice: number, referencePrice: number): number | null {
  if (!Number.isFinite(referencePrice) || referencePrice <= 0 || !Number.isFinite(tokenPrice)) return null;
  return ((tokenPrice - referencePrice) / referencePrice) * 100;
}
